Privacidade e termos

O Caderno é uma aplicação de código aberto que corre no teu computador. Não tem servidor próprio nem contas, e quem o desenvolve não recebe os teus ficheiros, o teu progresso nem as tuas chaves.

Onde ficam os dados

Os materiais ficam em Documentos\Caderno\Materiais, numa pasta por cadeira. A base de dados, a chave local de proteção e as definições ficam em %APPDATA%\Caderno\Dados. Nas Definições da aplicação podes exportar os dados ou apagar tudo.

Moodle

Se ligares o Moodle, o Caderno envia o utilizador e a palavra-passe à plataforma que indicaste para obter uma chave de acesso. A palavra-passe não é guardada; a chave fica cifrada no teu computador. O acesso aos materiais continua sujeito às permissões da tua conta Moodle. Para revogar a chave, usa a página Chaves de segurança do teu perfil no Moodle.

Inteligência artificial

A IA é opcional. Só depois de configurares a tua chave e autorizares a análise é que o texto de PDFs não classificados como sensíveis é enviado, a partir do teu computador, ao fornecedor que escolheste. Esse fornecedor pode cobrar os pedidos e trata os dados segundo a sua própria política. Podes retirar a autorização quando quiseres.

Este site

Este site não usa cookies nem ferramentas de análise. Guarda apenas o tema que escolheres no teu browser. Para mostrar a versão mais recente, o browser consulta a API pública do GitHub, e os instaladores são descarregados das releases do GitHub. O alojamento do site pode registar dados técnicos de acesso, como o endereço IP, segundo as regras do fornecedor de alojamento.

Termos de utilização

O Caderno é distribuído sob a licença MIT, sem garantias. É uma ferramenta independente, sem afiliação ao Moodle. Usa apenas materiais a que tens direito de acesso. Os resumos e as explicações ajudam a estudar mas podem conter erros: confirma sempre na fonte.

Para problemas ou sugestões, abre uma issue no GitHub.
