Cada cadeira arrumada, o próximo passo à vista.

O Caderno é uma aplicação para Windows que junta os materiais e prazos de cada cadeira, monta o plano do dia e dá-te flashcards, treino e simulados. Funciona com o Moodle ou com os teus ficheiros.

1Como funciona

O Moodle é opcional. Contas com autenticação única (SSO) podem não conseguir ligar; nesse caso, envia os ficheiros à mão.

Do material ao próximo passo

  1. Instala e segue o guia

    Na primeira vez, um guia curto ajuda-te a juntar as cadeiras, indicar o tempo que tens e, se quiseres, configurar a IA.

  2. Junta as cadeiras

    Liga o Moodle da tua instituição para importar ficheiros e prazos, ou cria cadeiras e envia os teus ficheiros.

  3. Estuda o passo seguinte

    O Hoje mostra o que mudou, os prazos e os blocos de estudo. O plano volta a ser calculado quando marcas um bloco como estudado.

3Descarregar

No teu computador

O Caderno corre só no teu Windows. Não há conta, nem servidor: os materiais ficam numa pasta tua, separados por cadeira.

Pelo site

Descarrega diretamente o instalador da versão mais recente.

Descarregar para Windows

Pelo GitHub

Escolhe a versão na página de releases, com as notas de cada uma e as anteriores.

Descarregar no GitHub

O ficheiro vem sempre das releases do GitHub. O instalador atual ainda não tem assinatura de código, por isso o Windows pode mostrar um aviso de editor desconhecido. O Caderno planeia usar a SignPath Foundation para assinar futuras versões. Instruções de instalação · Code signing policy.

Materiais
Em Documentos\Caderno\Materiais. Se o Windows redirecionar Documentos para o OneDrive, o Caderno usa essa pasta.
Sem internet
Os PDFs já importados abrem no visualizador da aplicação. Resumos, perguntas e flashcards já criados continuam disponíveis.
Com internet
Sincronizar o Moodle e fazer pedidos à IA.

Formatos aceites, até 20 MB

PDF abre dentro do Caderno e é o único formato analisado pela IA.

DOCX, PPTX, XLSX, ODT, ODP, ODS, DOC, PPT, XLS, TXT, MD, CSV, RTF, EPUB e ZIP ficam guardados e abrem com os programas do teu computador.

4IA opcional

A tua chave, a tua escolha

Sem chave, ficheiros, plano e progresso funcionam na mesma. Com a tua chave, os PDFs passam a ter resumos e perguntas para estudar.

  1. Escolhes o fornecedor A Groq tem um plano gratuito, sem cartão, e o guia mostra como criar a chave. Também funcionam Anthropic, OpenAI, DeepSeek e outros serviços compatíveis com Chat Completions.
  2. Autorizas a análise O envio de texto à IA tem um consentimento próprio, que podes retirar quando quiseres.
  3. Pedes o resumo Num PDF ou para os PDFs pendentes. Importar ficheiros ou sincronizar o Moodle nunca inicia uma análise.

Cada pedido vai diretamente do teu computador para o fornecedor, que o pode cobrar na tua conta. A chave fica cifrada no computador e não aparece na exportação de dados.

Sem conta, sem servidor

Não há nada para registar. Os ficheiros, o progresso e as chaves ficam no teu computador; a aplicação comunica com o Moodle, o fornecedor de IA que escolheres e o GitHub para procurar atualizações.

O que controlas

Exportar os dados, apagar tudo, desligar o Moodle, escolher o fornecedor de IA e retirar a autorização de análise.
